From lidar returns to a warning

The M1 supplies measured geometry. Comma supplies a predicted path and motion information. Tracking and collision checks combine them; the safety checks determine whether an advisory can be spoken.

Unknown obstacles can matter

A car, deer, or person label is not required for the live geometric collision check.

Object labels belong to offline review

Tentative camera–lidar associations do not enter the live warning decision.

Advisory output only

This FCW application does not steer, brake, or command vehicle actuators.

Source-based explanation

“AI-assisted development” is a different layer

AI helped develop and review this project. That describes how the code was built. The deployed live warning path does not ask a conversational AI to interpret each scan.

Its runtime neural inputs come from Comma. The separate offline YOLOX pass adds tentative object labels for visual review.

Learning happens between recordings

The bounded worker indexes drives, preserves route memory, extracts raw Honda radar, and fits a small non-neural forecast model. Separate physical driving groups must validate an improvement before automatic selection for a later session.

Unqualified candidates remain research evidence. This learner does not retrain YOLOX or the Comma model, establish collision reliability, or clear calibration and confidence gates.
